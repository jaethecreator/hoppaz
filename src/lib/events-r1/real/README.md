# The real data layer

`real/` is the `EventsR1Api` on Ola's database. Every method is one call to a function in `supabase/events_r1_*.sql` (RPC only, with the signed-in session), and the answer is mapped to the same types and the same error words as `fake/`, which is the spec: a reason code like `no_free_place` becomes "No free place. Raise the capacity first." (`core.ts` holds the table, `map.ts` the jsonb to type mapping, one file per domain after that). It is used when `NEXT_PUBLIC_EVENTS_R1=1` and `NEXT_PUBLIC_EVENTS_R1_FAKE` is not 1. Subscriptions are a shared emitter: every write of ours, every sign-in change and a 20 second poll (only while a screen listens and the tab is visible) make the hooks reload. Sign-in keeps a guest's progress by adding the email to the guest's own user (`updateUser`, then the `email_change` code); someone with no session, or an email that already has an account, signs in with the plain `email` code. Paid tickets call the route handlers in `src/app/api/events-r1/pay/*` with the access token and read through the `ev_pay_*` functions. Staff reports go through the staff route `/api/admin/event-reports` with the desk's token, because the two database functions are service-role only.

Where the drafts have no function the layer uses what the app already has, and says so: chat is the existing tables (General is `crew_room_messages` written by `crew_room_send`, an event's chat is `messages` with the event id as its channel, and a person who may enter gets the app's own "I'm going" swipe, because `in_room` does not know registrations yet), a room is made and joined with `create_crew` and `join_crew`, announcements are posted with `crew_announce`, interest is the `swipes` table, and who owns a room comes from `crew_members`. The gaps are three Pop calls (`cancelScheduled`, `setAuto`, `editAuto` answer "Not available yet"), `events.update` with `add_to_room`, and a room description (`create_crew` has none). The run-through that proves it all is `scripts/events-r1-real-check.mts` (local stack only).
